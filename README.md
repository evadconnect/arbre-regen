# L'arbre REGEN d'EVAD

Visualisation interactive de l'écosystème régénératif d'EVAD, sous forme d'arbre : les racines (les cinq piliers), le tronc (la valeur, « du rêve à la preuve »), les cinq branches (les étapes du parcours REGEN) et la boucle du vivant qui ramène les résultats vérifiés vers les racines.

Une seule page HTML autonome (`arbre-regen-evad.html`), sans build : SVG inline interactif, panneau de détail, bascule thème clair/sombre, accessible au clavier et respectant `prefers-reduced-motion`.

## Utilisation

Ouvrir `arbre-regen-evad.html` dans un navigateur. Aucune dépendance à installer ; les polices sont chargées via CDN avec repli système hors ligne.
